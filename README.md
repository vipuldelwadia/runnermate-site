# PR screenshots for vipuldelwadia/runnermate

That repo is private, so an image linked from one of its branches does not
render in a pull request body: GitHub fetches images through a proxy with no
access to the repo. This branch is public and is never deployed to r.ac.nz,
which builds from `main` only.

One folder per PR branch, with the slashes in the branch name turned into
hyphens. Link each file by its raw URL:

    https://raw.githubusercontent.com/vipuldelwadia/runnermate-site/pr-screenshots/<folder>/<name>.png

Push with a plain commit on this branch. Never force-push, since PR bodies
link to the files by path.
